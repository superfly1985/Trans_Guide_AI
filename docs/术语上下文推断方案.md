# 术语上下文推断方案

## 项目背景
- 行业单一但术语存在多译词（如 cell -> 单元格|细胞|电池）
- 必须从上下文推断最合适的译词
- Token 消耗不是主要问题

## 实施计划

### 阶段1：核心功能实现

#### 1.1 创建 context_resolver.py 模块
**文件**: `modules/context_resolver.py`
**功能**: 根据上下文推断最合适的译词
**关键内容**:
- ContextResolver 类
- DOMAIN_KEYWORDS 领域关键词映射
- resolve() 方法：根据文本上下文选择译词

#### 1.2 修改 term_db.py
**文件**: `modules/term_db.py`
**修改内容**:
- 添加 get_term_with_context() 方法
- 支持解析多译词（用 | 分隔）
- 调用 ContextResolver 进行选择

#### 1.3 修改 app.py 批量翻译
**文件**: `web/app.py`
**修改内容**:
- 修改术语匹配逻辑，传入上下文
- 使用新的带上下文的术语查询方法

### 阶段2：增强功能

#### 2.1 文件类型预设
**功能**: 根据上传文件类型预设领域
**实现**:
- Excel 文件 -> 默认 Excel 领域
- 生物学文档 -> 检测关键词自动推断
- 可扩展其他文件类型

#### 2.2 用户反馈机制
**功能**: 记录用户修正，优化关键词
**实现**:
- 添加术语修正记录表
- 统计用户选择，调整默认优先级

## 数据结构

### 术语存储格式
```
source_term | target_term
cell        | 单元格|细胞|电池
bank        | 银行|河岸|库
```

### 领域关键词映射
```python
DOMAIN_KEYWORDS = {
    'excel': ['单元格', '工作表', '公式', '函数', '表格'],
    'biology': ['细胞', '基因', '蛋白质', '组织', '生物'],
    'power': ['电池', '电压', '电流', '充电', '电源'],
    'finance': ['银行', '账户', '存款', '贷款', '金融'],
    'geography': ['河岸', '河流', '地形', '地貌', '地理'],
    'programming': ['库', '函数库', '代码库', '编程'],
}
```

## API 变更

### 批量翻译接口
- 接收文件类型参数（可选）
- 根据文件类型预设领域
- 使用上下文推断选择术语

## 测试验证点
1. 多译词术语能正确解析
2. 上下文推断准确
3. 文件类型预设生效
4. 无上下文时默认第一个译词
