# TransGuide 系统架构设计文档

> 最后更新: 2026-05-02 | 版本: v1.3.0

## 一、系统概述

TransGuide 是一个作业指导书智能翻译系统，支持 PDF、Word、Excel（含中国表）、PPT 等文件格式的翻译。采用 Flask + SQLite + ChromaDB + LLM 的技术栈。

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 原生 HTML/JS/CSS | 无框架依赖，Linear深色设计风格 |
| 后端 | Flask (Python) | RESTful API |
| 数据库 | SQLite3 | 用户/术语/翻译记忆 |
| 向量库 | ChromaDB | 翻译记忆相似检索 |
| LLM | MiniMax API | 翻译+术语提取 |
| 文件处理 | python-docx, openpyxl, python-pptx, PyPDF2 | 文档解析与生成 |

## 四、数据库设计

### 4.1 用户表 (users)
```sql
users: id, username, email, password_hash, salt, role, status,
       refresh_token, created_at, updated_at, last_login
```

### 4.2 术语表 (terms + term_categories + term_feedback)
```sql
terms: source, target, category, tags, notes, created_at
term_categories: id, name, created_at
term_feedback: id, term_source, current_target, suggested_target,
               feedback_type, user_id, status
```

### 4.3 翻译记忆表 (translation_memory)
```sql
translation_memory: id, original, translation, source_file,
                    duplicate_count, quality_score, created_at, updated_at
```

### 4.4 翻译历史记录表 (translation_history)
```sql
translation_history: id, user_id, username, original_filename,
                     output_filename, file_type, summary, block_count,
                     total_chars, mode, source_lang, target_lang, status
```

### 4.5 LLM使用统计表 (llm_usage)
```sql
llm_usage: id, user_id, operation_type, model_name, input_tokens,
           output_tokens, total_tokens, response_time_ms, status
```

### 4.6 系统统计快照表 (system_stats)
```sql
system_stats: id, stat_date, total_users, active_users_7d, active_users_30d,
              total_files, files_today, llm_calls_today, llm_tokens_today
```

## 五、权限系统

### 三级角色
| 角色 | 翻译 | 术语管理 | 记忆管理 | 术语提炼 | 用户管理 | 统计面板 |
|------|:----:|:--------:|:--------:|:--------:|:--------:|:--------:|
| admin (管理员) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| manager (主管) | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ |
| user (普通用户) | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |

### 认证流程
1. 用户登录 → 后端返回 refresh_token (64位hex)
2. token 存入 localStorage + 数据库
3. 每次打开页面 → 前端自动调 `/api/auth/refresh` → 无感登录
4. API 端点通过 `@login_required` 装饰器验证 `X-User-ID`

## 六、API设计

### 认证模块
| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/auth/login` | POST | 登录 |
| `/api/auth/register` | POST | 注册 |
| `/api/auth/refresh` | POST | 自动刷新登录 |
| `/api/auth/user` | GET | 获取当前用户信息 |

### 术语模块
| `/api/terms` | GET/POST | 获取/添加术语 |
| `/api/terms/<source>` | PUT/DELETE | 更新/删除术语 |
| `/api/terms/categories` | GET/POST/DELETE | 分类管理 |
| `/api/terms/feedback` | GET/POST | 术语反馈 |

### 翻译记忆模块
| `/api/memory` | GET | 获取记忆列表 |
| `/api/memory/add` | POST | 手动添加记忆 |
| `/api/memory/<id>` | PUT/DELETE | 编辑/删除记忆 |
| `/api/memory/search` | GET | 搜索记忆 |
| `/api/memory/duplicates` | GET/POST | 重复检测/合并 |
| `/api/memory/cleanup` | POST | 清理低质量 |

### 翻译模块
| `/api/translate/text` | POST | 文本翻译 |
| `/api/translate/file` | POST | 文件翻译 |
| `/api/translate/history` | GET | 翻译历史 |
| `/api/extract/terms` | POST | 术语提取 |

### 管理模块
| `/api/admin/users` | GET | 用户列表 |
| `/api/admin/users/<id>` | PUT | 编辑用户 |
| `/api/admin/users/<id>/approve` | POST | 审批用户 |
| `/api/admin/users/<id>/disable` | POST | 禁用用户 |
| `/api/admin/stats/overview` | GET | 统计概览 |
| `/api/admin/stats/trend` | GET | 趋势数据 |
| `/api/admin/stats/detail` | GET | 详细统计 |

## 七、前端架构

### 视图切换
基于 `data-view` 属性的单页视图切换，当前支持的视图：
- `textTranslate` - 文本翻译
- `fileTranslate` - 文件翻译
- `importFile` - 导入历史文件
- `termView` - 术语管理
- `memoryView` - 记忆管理
- `historyView` - 翻译历史
- `adminView` - 用户管理
- `statsView` - 统计面板

### UI设计规范 (Linear 深色模式)
- 主背景: `#0f0f11` | 卡片: `#18181b` | 边框: `#27272a`
- 标题: `#fafafa` | 正文: `#e4e4e7` | 辅助: `#a1a1aa`
- 品牌色: `#3b82f6` | 成功: `#22c55e` | 危险: `#ef4444`
- 圆角: 6-8px | 间距: 12-24px | 字号: 12/14/18px
