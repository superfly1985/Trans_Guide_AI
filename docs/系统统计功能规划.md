## 四、数据库设计

### 4.1 新增表: llm_usage (LLM调用记录)

```sql
CREATE TABLE llm_usage (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    operation_type TEXT,           -- 操作类型: 'translate', 'extract_terms', 'analyze', 'batch_translate'
    model_name TEXT,               -- 模型名称: 'MiniMax-M2.7', 'GPT-4' 等
    input_tokens INTEGER,          -- 输入token数
    output_tokens INTEGER,         -- 输出token数
    total_tokens INTEGER,          -- 总token数
    response_time_ms INTEGER,      -- 响应时间(毫秒)
    status TEXT,                   -- 状态: 'success', 'failed', 'timeout'
    error_message TEXT,            -- 错误信息(失败时记录)
    request_size_bytes INTEGER,    -- 请求体大小
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 索引
CREATE INDEX idx_llm_usage_user_id ON llm_usage(user_id);
CREATE INDEX idx_llm_usage_created_at ON llm_usage(created_at);
CREATE INDEX idx_llm_usage_operation ON llm_usage(operation_type);
```

### 4.2 新增表: system_stats (系统统计快照)

```sql
CREATE TABLE system_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    stat_date DATE UNIQUE,         -- 统计日期
    
    -- 用户统计
    total_users INTEGER DEFAULT 0,
    active_users_7d INTEGER DEFAULT 0,
    active_users_30d INTEGER DEFAULT 0,
    new_users_today INTEGER DEFAULT 0,
    
    -- 翻译统计
    total_files INTEGER DEFAULT 0,
    files_today INTEGER DEFAULT 0,
    total_words_translated INTEGER DEFAULT 0,
    
    -- 术语统计
    total_terms INTEGER DEFAULT 0,
    new_terms_today INTEGER DEFAULT 0,
    
    -- LLM统计
    llm_calls_today INTEGER DEFAULT 0,
    llm_tokens_today INTEGER DEFAULT 0,
    llm_errors_today INTEGER DEFAULT 0,
    
    -- 系统统计
    db_size_bytes INTEGER DEFAULT 0,
    log_size_bytes INTEGER DEFAULT 0,
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_system_stats_date ON system_stats(stat_date);
```

### 4.3 新增表: term_feedback (术语反馈)

```sql
CREATE TABLE term_feedback (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    term_source TEXT,              -- 术语原文
    current_target TEXT,           -- 当前译法
    suggested_target TEXT,         -- 建议译法
    feedback_type TEXT,            -- 类型: 'incorrect', 'better', 'missing'
    user_id INTEGER,               -- 反馈用户
    status TEXT DEFAULT 'pending', -- 状态: 'pending', 'approved', 'rejected'
    admin_notes TEXT,              -- 管理员备注
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    resolved_at TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 索引
CREATE INDEX idx_term_feedback_status ON term_feedback(status);
CREATE INDEX idx_term_feedback_created ON term_feedback(created_at);
```

### 5.2 组件说明

#### 概览卡片
- 4个主要指标卡片，带图标和趋势箭头
- 点击卡片可切换下方图表维度
- 悬停显示详细tooltip

#### 趋势图表
- 使用 Chart.js 实现
- 支持折线图、柱状图、饼图切换
- 可对比多个维度数据
- 支持缩放和拖拽

#### 详细数据表格
- Tab切换不同数据维度
- 支持排序、筛选、分页
- 支持列显示/隐藏
- 支持数据导出CSV

## 八、技术选型

| 组件 | 技术方案 | 理由 |
|------|----------|------|
| 图表库 | Chart.js v4.x | 轻量、美观、支持暗黑模式、响应式 |
| 表格组件 | 原生HTML + JS | 复用现有用户管理表格样式，保持统一 |
| Excel导出 | SheetJS (xlsx) | 纯前端实现，无需后端依赖 |
| CSV导出 | 原生Blob API | 简单高效 |
| 定时任务 | APScheduler | Python生态成熟，集成简单 |
| 数据缓存 | 内存缓存 (前期) | 简单实现，后期可升级Redis |

## 九、注意事项

### 9.1 性能考虑
- 大数据量查询需分页，避免一次性加载
- 统计接口添加缓存，减少数据库压力
- 趋势数据可预计算，定时更新而非实时计算

### 9.2 数据安全
- 统计接口仅限管理员访问
- 敏感数据脱敏 (如用户邮箱)
- 导出功能添加权限校验

### 9.3 兼容性
- 保持与现有Linear深色风格统一
- 响应式设计，支持不同屏幕尺寸
- 浏览器兼容性: Chrome/Firefox/Edge 最新版
